# 🌌 Galactic Singularity ULTRA 2.0

Ein vollständiges, einheitliches KI-System mit galaktischer Singularität als visuelles Portal zu einem erweiterten KI-Chat mit allen integrierten Funktionen.

## ✨ Features

- 🌌 **Interaktive Galaktische Singularität** - Anklickbarer Button mit animierter Singularität
- 💬 **KI-Chat** - Vollständiger Chat mit mehreren AI-Modulen
- ⚛️ **Quantum AI** - Raumzeit-Simulation und Quantenmechanik
- 🌸 **Lebensblume AI** - Heilige Geometrie und harmonische Strukturen
- 🕉️ **Urspirit AI** - Bewusstseinsfeld und spirituelle Weisheit
- 💰 **Finance Agent** - Wohlstands-Energie und finanzielle Freiheit
- 🎨 **Creator Agent** - Kreative Inspiration und Design-Hilfe
- 📢 **Social Agent** - Community-Strategien und Netzwerk-Expansion
- 🔐 **Authentifizierung** - Benutzer-Registrierung und Login
- 📝 **Chat-Verlauf** - Speicherung und Abruf von Chats
- 🔗 **OpenAI Integration** - Optional für erweiterte AI-Responses
- 📱 **Responsive Design** - Mobile-optimierte Oberfläche

## 🚀 Schnellstart

### Anforderungen
- Python 3.8+
- Flask 2.3.0+
- Werkzeug 2.3.0+

### Installation

```bash
# Klone das Repository
git clone https://github.com/DEINNAME/galactic-singularity-ultra.git
cd galactic-singularity-ultra

# Installiere Dependencies
pip3 install -r requirements.txt
```

### Starten

```bash
# Option 1: Mit GO.py
python3 GO.py

# Option 2: Mit TEST.py (Zuerst testen)
python3 TEST.py

# Option 3: Mit app_unified.py direkt
python3 app_unified.py
```

Öffne dann im Browser: `http://localhost:5000`

Klick auf die 🌌 **Galaktische Singularität** und das Chat-Portal öffnet sich!

## 🔧 API Endpoints

- `GET /` - Hauptseite
- `POST /chat` - KI-Chat Endpoint
- `POST /register` - Benutzer-Registrierung
- `POST /login` - Benutzer-Login
- `GET /logout` - Benutzer-Logout
- `GET /history` - Chat-Verlauf abrufen
- `GET /api/status` - API-Status
- `POST /api/clear-history` - Chat-Verlauf löschen

## 💾 Datenbank

SQLite mit folgenden Tabellen:
- `users` - Benutzerkonten
- `chat_history` - Chat-Verlauf
- `memory` - Benutzer-Memory
